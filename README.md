# Creative AI Studio

Build a complete production-ready AI SaaS web application called AI Content Creator Studio.

Tech Stack:

- React + TypeScript + Vite

- Tailwind CSS

- Node.js + Express

- MongoDB Atlas

- JWT Authentication

- Cloudinary

- Framer Motion

The application must be fully responsive and support both Dark and Light themes.

Main Features:

1. AI Social Media Post Generator

- Generate Instagram, Facebook, LinkedIn, Twitter posts.

- Multiple languages.

- Generate captions, emojis and hashtags.

- Tone selection.

2. Promotional Product Generator

- User uploads product image.

- AI writes product description.

- CTA generation.

- SEO keywords.

3. AI Image Studio

- Generate posts & story images.

- Multiple styles.

- Download HD image.

4. AI Story Generator

- Instagram story templates.

- Text overlays.

- AI generated backgrounds.

5. AI Music Suggestion

- Analyze generated image.

- Recommend Spotify tracks using Spotify API.

6. Favorites

- Save generated content.

- Like button.

- Personal library.

7. AI Reel Generator

Workflow:

Category → Prompt → AI Suggestions → Customize → Generate → Preview → Download

Customization:

- Style

- Voice

- Language

- Duration

- Music

- Aspect Ratio

Generate:

- Script

- Captions

- Voiceover

- Visuals

- Background music

8. Analytics Dashboard

- Generated posts

- Downloads

- Favorites

- Engagement predictions

UI Requirements:

- Premium SaaS

- Glassmorphism

- Purple + Blue gradients

- Rounded cards

- Minimal icons

- Smooth animations

Generate complete frontend + backend with folder structure, routing, API integration placeholders and MongoDB models.
